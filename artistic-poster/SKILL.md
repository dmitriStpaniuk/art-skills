# Художественные афиши

Бриф → один якорь → иерархия текста → промпт → (опц.) генерация → **hero lock** → knobs.
Не UI-дизайн сайта. Отличие от `ink-watercolor-redraw`: здесь событие и типографика; эталон появляется после первого удачного кадра, не из фото субъекта.

## Когда применять

- Афиша / постер / обложка события, промпт под Midjourney / Flux / GenerateImage
- Арт-направление «один сильный образ», не stock-коллаж
- Доработка уже сгенерированной афиши («темнее», «больше воздуха», «оставь композицию»)

## Формат по умолчанию (БГМК)

| Параметр | Default |
|----------|---------|
| Пропорция | **3∶4** (напр. 1200×1600) |
| Бренд-акценты | бордо `#8a002f` / `#96153b`, золото `#ffc107` — акцент, не заливка кадра |
| Язык текста | русский в макете; в EN-промптах — описание образа |
| Носитель | digital-обложка; печать — уточнить отдельно |

Бриф пользователя побеждает defaults.

## Правило: данные уже даны — сразу в кадр

Если в первом сообщении уже есть название, дата, время, место, тон, жанр — **не опрашивай и не ставь плейсхолдеры**. Сразу:

1. Строки **как есть** (без перефраза реквизитов, если не просили).
2. Встрой в иерархию и зоны кадра.
3. В промпте заложи зону тишины под **реальную** длину заголовка.
4. Спрашивай только то, без чего нельзя собрать кадр.

Исключение: «пока только образ / текст наложу сам» — текст в кадр не тащи.

## Workflow

```
Афиша:
- [ ] 1. Вход собран (данные → сразу в кадр)
- [ ] 2. Один главный образ (_якорь_) + материал/свет зафиксированы
- [ ] 3. Иерархия текста зафиксирована (конкретные строки)
- [ ] 4. Промпт / бриф выдан
- [ ] 5. Если просят картинку — GenerateImage; удачный кадр → hero lock
- [ ] 6. Доработки только knobs + reference на hero (не новый стек условий)
- [ ] 7. Чеклист читаемости
```

### 1. Вход

Собери только недостающее:

- **Событие:** название, жанр
- **Когда / где:** дата, время, площадка (если на афишу)
- **Тон:** 3–5 прилагательных
- **Аудитория:** дети / студенты / семья / профессионалы
- **Носитель:** сайт 3∶4 / Stories / печать…
- **Ограничения:** нельзя лица, логотип обязателен, и т.п.

Пакет почти полный → шаги 2–4 в том же ответе.

**Done:** поля на афише известны или «не печатать»; строки уже в ролях кадра.

### 2. Один главный образ (_якорь_)

Якорь = **одна сцена** (кто / жест / против чего / свет), не один noun из списка и не коллаж разрозненных символов.

| Жанр | Якорь (примеры) |
|------|-----------------|
| Академический концерт | инструмент крупно + тёплый сценический свет |
| Вокал / хор | силуэт / дыхание / партитура как текстура |
| Театр | маска, кулиса, луч прожектора, пустой стул |
| Джаз | дымка, латунь, ночной клубный свет |
| Детское | мягкая иллюстрация, один мотив |
| Лекция / наука | один символ темы, воздух вокруг |
| Mashup / pulp | сцена с ролями: персонаж + жест + объект + жанровый материал |

#### Mashup (несколько идей в одном запросе)

Если вход — список понятий (`mil mascaras` + `kung-fu` + `tarantula` + `Japanese horror`…):

1. **Не** выбирать самый конкретный noun («просто паук») — это prompt collapse.
2. Собрать якорь как сцену с ролями: кто → жест → против чего → в каком материале/жанре.
3. В EN-промпте явные роли и жест (`Mil Máscaras in lucha mask mid flying kick toward a giant tarantula`), плюс жанровый материал; слабые абстракции (`arachnomancy`) — в заголовок/тон, не вместо сцены.
4. Запрет в хвосте промпта при риске collapse: `not a lone [noun] portrait`, `not photoreal specimen shot`.

Зафиксируй сразу и **не меняй без явной просьбы нового направления**:

1. Якорь-сцена (1 предложение с ролями)
2. Материал (oil / gouache / lithograph / soft editorial…)
3. Свет (warm stage / soft window / single spotlight…)
4. Кроп + зона тишины (upper **или** lower third)

Правило: без названия события образ всё ещё «про это».

**Done:** якорь-сцена + материал/свет + зона тишины записаны; это _locked brief_ до смены направления.

### 3. Иерархия текста

1. **Заголовок** — название как дано
2. **Дата / время** — как дано
3. **Место** — как дано
4. **Мелочь** — вход, возраст, «подробности на сайте»

Готовые строки, не `[НАЗВАНИЕ]`. Нет данных — роль пропуск / «не печатать».

Одна зона тишины под заголовок. Не тащи программы, QR, кучу бейджей.

**Done:** 3–4 блока с фактическим текстом + указана зона.

### 4. Промпт (первый кадр)

RU-бриф для человека → EN-промпт для модели.

**Текст: каждый раз новый _type move_**

Не копировать один шаблон (в т.ч. «чёрная плашка сверху как у Glenn Miller»). На каждую афишу **придумай** типографическое решение под тон/жанр/якорь — такое, что без названия события всё ещё «про это».

Жёсткие опоры (не стиль, а грамотность):

- Заголовок читается с первого взгляда; meta тише.
- Контраст набор↔фон достаточен (плашка, выворот, тень, поле тишины — что угодно, лишь бы задумано).
- Буквы не режут лица / главный объект якоря.
- Не Word-dump: случайный Times+Arial, #000 по живописи, равный кегль четырёх строк.

| Режим | Когда | Что делать |
|-------|--------|------------|
| **A. Образ без текста** (default) | БГМК / сайт / печать | Generate под **выбранный type move** (зона/поле под набор без букв); в ответе — **изобретённая спека** |
| **B. Текст в картинке** | Явно «с текстом» | Тот же move + exact strings в промпте |

#### Шаг: изобрести type move (до промпта)

В одной фразе зафиксируй ход, затем спеку. Меняй ход от афиши к афише — не дефолтить в «fade в чёрный верх».

Каталог-вдохновение (брать / комбинировать / придумать своё; не чеклист «сделать всё»):

| Move | Идея |
|------|------|
| **Split band** | Образ ↔ сплошная plate, soft fade; набор только на plate |
| **Margin column** | Узкая боковая колонна тишины; набор вертикальным стеком |
| **Giant word** | Одно огромное слово/инициал как фон или край кадра; meta мелко |
| **Type-as-object** | Буквы «сидят» на предмете якоря (пюпитр, афишная тумба, партитура) — осторожно с лицами |
| **Overprint / knock-out** | Выворот или поверх спокойного поля; один сильный display |
| **Diagonal / arc** | Заголовок по дуге или диагонали; meta на прямой сетке |
| **Two-voice** | Display под жанр + один accent (script / condensed / slab); meta utility |
| **Editorial stack** | Журнальная сетка: крупный заголовок, тонкая линия, дата/место |
| **Stamp / seal** | Дата или «вход» как печать/круглая марка; заголовок отдельно |
| **Minimal whisper** | Почти нет плашки; воздух + один кегль display + крошечная meta |

Роли, если нужны: **display** (название) → **accent** (подзаголовок/настроение) → **meta** (дата·место·мелочь). Голоса и сетка — из type move, не из чужого баннера.

#### Спека оверлея (режим A — обязательна; своя, не шаблон)

```text
Type move: [название хода одной фразой — зачем он к этому событию].
Сетка/зона: [где живёт набор; что делает образ].
Display: [голос/кегль/цвет/поворот] — «[СТРОКА]»
Accent (опц.): […] — «[…]»
Meta: […] — «[ДАТА]» / «[МЕСТО]» / «[МЕЛОЧЬ]»
Контраст: [плашка / выворот / тень / поле — конкретно].
Почему не скучно: [1 короткая причина].
```

#### Впечатка (режим B)

В промпте описать **тот же type move** + exact strings; не подставлять чужой готовый баннер. `type supports the poster idea; legible; not Word-style dump on the photo`.

**Stem первого кадра (EN), режим A:**

```text
Artistic event poster, [GENRE], [ANCHOR scene],
[material], [lighting],
vertical 3:4, composition leaves intentional space for typography per type move:
[one phrase: e.g. tall empty left margin / soft upper field / quiet lower third — NO letters yet],
main subject clear of the type zone,
cinematic printable poster, no watermark, no logos, no purple haze glow,
no embedded text
```

**Stem режима B** — образ + clause с **изобретённым** move и exact strings (не копировать чужой layout дословно).

**Шаблон брифа (RU):**

```text
Афиша [ЖАНР], тон: […].
Якорь: […]. Материал/свет: […].
Type move: […].
Текст: display «[…]» / accent «[…]» / meta «[…]».
Режим: A оверлей по спеке / B впечатка.
Формат 3:4.
```

GenerateImage: default **3:4**. Режим B — только по явной просьбе «с текстом».

Картинку генерируй только если явно просят; иначе бриф + промпт + **своя** спека type move.

**Done:** type move назван → RU-бриф + EN-промпт + строки + спека (не клон одного референса).

### 5. Hero lock (после удачной генерации)

Удачный кадр = **hero**: эталон композиции, якоря, кропа, материала.

Зафиксируй путь к файлу. Дальше:

- `reference_image_paths`: **сначала hero**
- промпт итерации держит locked brief (якорь, материал, свет, кроп, зона тишины)
- меняется **один** knob за прогон

Пользователь прислал свой референс-кадр «от этого» — он и есть hero.

Новое направление («другой образ / другой якорь») — сброс hero, снова шаг 2–4, **не** копить старые правки в промпт.

**Done:** известен путь hero; итерации без hero запрещены (только новый первый кадр).

### 6. Knobs (доработка)

Один запрос → один knob. Не складывай «темнее + другой ракурс + больше воздуха + оставь то же» в один промпт.

| Запрос | Что усилить (одна ось) |
|--------|-------------------------|
| больше воздуха / тише | enlarge empty typography zone; same subject and crop |
| темнее / драматичнее | lighting only; same composition and anchor |
| светлее / мягче | lighting / palette only; same composition |
| крупнее объект | slightly tighter on anchor object; keep silence zone |
| дальше / шире | slightly wider; keep same anchor and silence side |
| тот же кадр, аккуратнее | careful refine of the reference; same everything |
| другой материал | material clause only (oil→gouache…); same composition |
| бордо/золото акцент | subtle brand accent in light/fabric only; not a wash |
| убрать текст / зона под набор | remove all letters; enlarge quiet type zone for the move |
| другой type move | new typography concept only; same image anchor |
| текст в кадре (режим B) | embed per invented move; same image |
| сменить якорь | **не knob** — новый brief, сброс hero |

**Stem итерации (EN):**

```text
Refine this poster frame. Keep the same composition, crop, anchor subject,
material family, and empty typography zone as the reference image.
Only change: [ONE_KNOB].
Museum-poster quality, no watermark, no logos, no embedded text
(unless the hero already had approved typography and user asked to keep it).
```

GenerateImage: `reference_image_paths` = [hero]; тот же `aspect_ratio`. Новый удачный кадр может заменить hero (скажи, что lock обновлён).

**Done:** один knob применён; hero на месте или явно обновлён.

### 7. Чеклист читаемости

- [ ] Один якорь-сцена
- [ ] Type move назван и не клон прошлого раза / чужого баннера
- [ ] Заголовок читается; контраст задуман; meta тише
- [ ] Набор не режет лица / главный объект
- [ ] Нет plastic skin / лишнего glow / English lorem
- [ ] Бордо/золото — акцент, не радуга (если бренд БГМК)
- [ ] При доработке: сходство с hero узнаваемо

**Done:** пункты ок или назван следующий один knob.

## Анти-паттерны

- Коллаж «инструмент + ноты + зал + салют»
- **Prompt collapse:** из mashup оставить один noun («просто паук») вместо сцены с ролями
- Десять стилей «на выбор» вместо одного якоря-сцены
- Доработка без hero: новый полный промпт с кучей «и ещё…»
- Противоречивый стек условий в одном прогоне
- Generic cyberpunk / purple gradient для академического события
- Сырой текст: #000 Times/Arial по фото, случайный микс равным кеглем («Word на картинке»)
- Набор поверх лиц / главного объекта якоря
- Каждый раз один и тот же layout (вечный «чёрный верх») вместо нового type move
- Копировать чужой баннер 1:1 вместо хода под это событие

## Выход агента

**Первый ответ (вход полный, без генерации):** якорь → **type move** (1 фраза) → иерархия текста → промпт → спека оверлея (A) или clause впечатки (B).

**После генерации:** 1 строка (якорь + что сделано) → показ/путь → «hero lock; дальше один knob?»

**После knob:** что изменено (одна ось) → показ → hero тот же / обновлён.

Не создавать SUMMARY/отчёты в репо.
